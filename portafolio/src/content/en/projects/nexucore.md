## Overview

**AriaTechShop ERP** is an enterprise resource planning (ERP) project built as a team to bring commercial management tools together into a single web application. It uses a decoupled architecture that separates the Laravel backend from the React and TypeScript web client.

### Backend

API and server logic built with **Laravel 12 and PHP**, using Composer for dependency management and Vite for server-side asset compilation.

### Frontend

Web interface built with **React 19 and TypeScript**, using React Router for navigation and Tailwind CSS for styling. Vite provides the development environment and the client build.

### Collaborative workflow

The repository documents a GitHub Flow based workflow, with a protected main branch, pull requests, code reviews, issue and PR templates, and branch naming conventions.
