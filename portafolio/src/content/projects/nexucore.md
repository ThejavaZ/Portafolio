## Descripción

**AriaTechShop ERP** es un proyecto de planificación de recursos empresariales (ERP) desarrollado en equipo para integrar herramientas de gestión comercial en una aplicación web. El proyecto utiliza una arquitectura desacoplada que separa el backend de Laravel del cliente web desarrollado con React y TypeScript.

### Backend

API y lógica del servidor desarrolladas con **Laravel 12 y PHP**, utilizando Composer para la gestión de dependencias y Vite para la compilación de recursos del servidor.

### Frontend

Interfaz web desarrollada con **React 19 y TypeScript**, utilizando React Router para la navegación y Tailwind CSS para los estilos. Vite proporciona el entorno de desarrollo y la compilación del cliente.

### Flujo de trabajo colaborativo

El repositorio documenta un flujo de trabajo basado en GitHub Flow, con protección de la rama principal, Pull Requests, revisiones de código, plantillas para Issues y PRs, y convenciones de nombres de ramas.
